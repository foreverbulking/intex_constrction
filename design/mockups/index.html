Why Redesign

Current site problems → what we fixed

Current site

  • Free-plan builder ads above the header and a "Created with Website.com" watermark in the footer.
  • No page title and no meta description — blank in search results and social shares.
  • Everything crammed onto one page — no dedicated Services, Projects, or Contact URLs.
  • Duplicate portfolio captions ("Ecole Macneill" repeated 4×) and a typo repeated twice.
  • Same photo reused as both the hero banner and the About background.
  • Logo is a soft 162×125 raster PNG — pixelates at any larger size.
  • Two extra web fonts loaded (Jost, neue-kabel) and never actually used on the page.
  • Thin calls to action — plain-text phone number, no form, no map.

This redesign

  • Custom-built site on your own domain — no builder ads, no watermark.
  • Unique, keyword-rich title and meta description on every page (see PLAN.md SEO section).
  • Five dedicated pages with real navigation and more SEO surface area.
  • Every project photo has a distinct, accurate caption and a category tag.
  • A distinct real photo per placement — no image repeated on the same page.
  • Clean logo treatment now; vector SVG recreation flagged for the build phase.
  • Two font families only (Space Grotesk + Inter), both used, nothing dead-loaded.
  • Click-to-call header phone, a real contact form, a map block, and a CTA band on every page.
